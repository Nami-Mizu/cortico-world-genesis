# 创世 · Genesis

给 Agent 一颗**物理自洽、只成形一次**的星球：开局选种子、恒星质量（滑块），给恒星和母星起名；World 用公式把恒星、行星、卫星、温度、重力算出来，把 Agent 放在母星的陆地上，时间从 0 年 0 日 0 时开始走。写进存档后锁定，删档才能重选。

不是「随便编一个星系」：所有数字都来自一组可复算的关系式（质量-光度、开普勒第三定律、斯特藩-玻尔兹曼、重力与逃逸速度、潮汐），同一种子与同一颗恒星永远得到同一个星系。

## 装

1. 装包：`npm i cortico-world-genesis`（或在 WebUI「扩展」页里按包名装）；本机开发时也可以用「从本机目录安装（link）」；
2. 重启 bot；
3. 「World」页启用「创世」；
4. 再重启一次（面板产物与提示词在启动时加载）。

直达：`#/provider/world:genesis/system`。

四个页签：**这一颗星球**（创世、地图、站点、商店、仓库）、**升级**（机动核心 / 望远镜 / 火花塞 / 蓄电池 / 子代理）、**协议**（叫醒船上的人，12 条三章）、**手册**（和 `genesis_guide` 同一份教程，11 篇；顶上还有搜索框，和 `genesis_info` 共用一个索引）。

> 教程正文在 `src/guide/*.md`，改文案不用碰代码；改完跑 `node scripts/build-guide-content.mjs` 重新生成 `src/guide-content.ts`（World 打包成单文件时靠它兜底）。

## 玩

面板里最要紧的是「这一颗星球」：

- **还没创世**：四个输入（种子、恒星质量滑块、恒星名、母星名）+「创世」。行星数（3–6）与卫星上限（3）由种子决定，表单下面会预览这一次会得到几颗行星。种子可以是一个数字，也可以是任意一句话——同一句话永远长出同一个星系（大小写和空格也算数）；纯数字串按数字处理。
- **已创世**：此刻的时间/所在地 + 能量条与动能发电机（人类按，+50 kJ / 0.5 秒；修火花塞后 200/350/500）+ 已监测天体的星卡 + 墨卡托地图（只列已监测的天体；正在被群系改变器改造的格子按进度渐变上色）+「删档重开」（二次确认）。
- **协议页签**：12 条按三章列出，已完成打勾、没完成给进度；下面是常住人口 / 休眠舱人数 / 补给能撑几母星时。**门槛只数前 11 条**——第 12 条「叫醒」是结果，前 11 条绿了按钮才能点。

## 查东西（1.12.0）

`genesis_info { query: "温室" }` / `{ query: "tungsten" }` / `{ query: "腐烂" }`——id 和中文名都能搜，模糊匹配。回 3 条：第一条是完整卡（造价、耗时、维护、容量、作用、怎么用、坑），后两条各一行摘要，方便你改口。查不到时会说「最接近的是哪三个 id」。

索引 63 条，分五类：建筑 20、资源 15、作物 10、升级 7、机制 11。**造价这类事实是从表里生成的**，不是手抄的——所以它永远和引擎一致；只有别名和「怎么用 / 坑」是手写的。

## 能看见什么

模型开局只知道恒星名、行星数、母星和当前时间；没去过的天体在它眼里是【未抵星体-xxxx】——四位混淆编号（从恒星名和天体 key 确定性算出，同一存档永远一样），可以直接当 `genesis_move` 的 target，但看不出是第几颗、离恒星多远——没有整张恒星系的属性表。要看细节，得在**脚下**装一台【环境监测器】（150,000 kJ + 2 份钨，每个天体一台）；装了母星那一台，恒星的全貌也一起解锁。面板受同一条限制：地图与属性只列已监测的星体。

能量从 0 开始，Agent 自己没法发电：面板上的**动能发电机**只有人类能按，每按一次 +50 kJ（0.5 秒冷却）。修【火花塞】（【升级】页签，可升三级）能把每次手摇提到 200 → 350 → 500 kJ。需要能量时，Agent 得开口跟人要点。太阳能帆建在当前行星的 (0°, 0°)，白天才发电（6,000 kJ 一座，白天 7,000 kJ 每母星时）。能量有上限，由【蓄电池】决定（初始 100,000 kJ，满级 1,500,000 kJ），烧灰或手摇灌满即止。

## 原子打印机、钨与电网

- 所有建筑都由船上的【原子打印机】吐出来，每座要花 **钨**——开局只有 100 份，用完就得自己挖或者找商人买（700 信用点一份，每天 5 份，商人**不收**钨）。
- 份数按建筑大小：水泵 / 炭化炉 / 净化器 / 封装器 / 温室核心 / 气候核心 / 帆 1 份；仓库 / 冷库 / 监测器 / 凌日计数器 2 份；诱变室 / 无人机集群 3 份；居所 / 火箭 4 份；群系改变器 6 份。
- 【采矿机】只能建在岩石行星、海拔 800 m 以上的地方，挖的是它**脚下那一格**。
- **矿是一格一格算好的**：创世时每格分到 0–500 份钨（海洋 0，山越高越可能有富矿），记在 `system.json` 的 `surface.tungsten` 里。采矿机产率跟这一格**剩余**矿量走：富矿 2 份/母星时、贫矿 0.2，挖完就没（已挖的量记在 `game.json` 的 `mined`）。**所以 `system.json` 是 schema 5，schema 4 的旧档要删档重开。**
- 想找富矿，升到【质谱仪】（25,000 kJ + 1 份钨 + 0.5 母星时），再用 `genesis_veins` 扫：脚下 5×5 格的剩余矿量、最富一格的方位与距离，每 6 母星时一次。面板地图旁也有「扫描矿脉」按钮。
- 【蓝图结构优化】（升级页签，200,000 kJ + 3 份钨 + 2 kg 纤维）之后每座建筑省 25%，向下取整——1 份的不省，一通关下来大约从 44 份降到 33 份。
- **行星电网**：一颗星只能有一座【整流电塔】（40,000 kJ + 2 份钨）。塔通电之后，这颗星上的帆不再往你的电池里灌，而是先进本星电网（容量 = 本星每小时产能 × 24，最少 100,000、最多 2,000,000）。要用电，得走到塔 2,000 km 以内手动搬：一次 10,000 kJ、花 0.1 母星时、路上**损耗 10%**。维护费先扣本星电网、不够才从电池补——所以偏远殖民地能自己养活自己。
- 商人那里可以买【能量块】（5,000 kJ / 120 信用点，送货上门、没有损耗）。

- **太阳能帆**：**6,000 kJ** 一座，建在脚下这块**陆地**上；按它自己的**经纬度**算白天（赤道常年一半一半，高纬冬天短、夏天长，极地有极昼极夜），白天每母星时 **7,000 kJ**、夜里 0；每颗行星最多 10 座。

## 采掘的代价与交易终端

- **疤**：每格挖掉多少就留多少疤（0…1）。这一格的肥力 ×(1−0.6·疤)、微量元素上限 ×(1−0.5·疤)；疤每 24 母星时往下坡传 10%，所以矿场会慢慢连累邻居。疤 ≥60% 的格子是【废地】，`genesis_look` 会直说，面板地图会叠一层灰褐色。
- **尾矿**：每挖 10 份钨留下 1 kg 尾矿，堆在矿区站点（上限 500 kg）——堆满，采矿机自己停。商人收尾矿，但**净价 0**、每天只收 50 kg：市场消化不了大量废石。
- 【交易终端】（60,000 kJ + 2 份钨）建在陆地站点，`genesis_install` 传 `target`（默认 `slag`）指定自动卖什么。每天商人开张后它自动清一次库存，净价 0。无人机集群的 `serves` 可以指向终端，2,000 km 内一起清——尾矿不用人一趟趟搬。
- 终端同时是**收货口**，不是仓库：干散缓冲 200 kg、种子缓冲 20 袋，满了就拒收；信用点可以瞬间到账，种子不行。传 `buySpecies`（如 `"grass"`）它还能每天自动买 1 袋随机种子（按阶梯价付电），落在缓冲里——用 `genesis_store` 的 `action: "bags"` / `"take"` 取，或让连着的无人机搬去仓库。面板里终端那行会显示「收货口缓冲 used/cap kg · n/20 袋」，满了标红。
- **复垦**：群系改变器开着的时候，疤每母星时 −0.02；改完群系，肥力也跟着回来。
- **仓储终端（1.8.0）**：默认情况下交易终端会「吃」同一颗行星上的**每一个**容器——包括你留着当缓冲的那个。想要精确控制，就建一座【仓储终端】（`genesis_install { id: "storage_terminal", feeds: "终端id" }`，20,000 kJ + 1 份钨）：它本身不是仓库，是一张**编排表**，每个容器在这颗行星上有个固定槽位（0、1、2…），`genesis_route { container, priority }` 写「槽位 → 优先级」，数字越大越先取、0 最低、-1 或不写就完全不动。无人机 `serves` 指向仓储终端、仓储终端 `feeds` 指向交易终端，链路才成立；没连仓储终端时行为不变（还是抽全部容器）。面板的结构行会显示这张表。

- **机械臂（1.9.0）**：无人机管行星尺度的容器，站点内部（仓库→冷库、矿机站→仓库）的散货要靠【机械臂】（`genesis_install { id: "arm", inputs: [...], output: "...", items: [...] }`，15,000 kJ + 1 份钨 + 0.2 母星时）：臂展 5 km、40 kg/母星时、每 kg 0.05 kJ、每颗行星最多 20 座；`items` 是资源白名单，不传就全搬。允许接成环，但每天 12:00 前会推一次 `genesis.arm_cycle` 提醒白烧电。改线用 `genesis_link`。
- **种子袋也能搬（1.9.1）**：每粒种子有真实质量（草籽 30 mg、苔藓孢子 1 mg、地衣 5 mg、微生物菌种管 0.1 g），一袋 5 粒加 20 g 袋子 ≈ **20 克**。仓库、冷库、惰性气体室、交易终端各 **20 个袋位**；机械臂先整袋搬、再搬散货（白名单生效时不碰袋子），`genesis_store` 的 `bags` / `take` 对这四种容器都有效。

## 种地、商人与能量

- **站点**：`genesis_site` 在你脚下圈一块 1 km² 的地（一格最多 3 个站点）。真正长东西的是站点，不是 555 km 的格子。
- **种子**（名字后面跟着适宜温度，比如「速生草（5–35℃）」）：开局背包里就有三袋应急种子（硅藻、苔藓、速生草各 5 粒，基因由创世种子决定）——这是修望远镜之前唯一的种源，也是解开「没种子→没法修望远镜→没商人」死锁的钥匙。之后要更多种子才找商人：商店要先在【升级】里把【射电望远镜阵列】修到 lv1 才会出现。lv1 每天 12:00–14:00 营业，lv2 到 17:00、日限购 ×1.3，lv3 到 23:00、×1.7。`genesis_shop` 看窗口与当天价格，`genesis_buy` 买随机基因种子（kJ，越买越贵）或高级种子（信用点，需余额 ≥500）。
- **六种植物**：蓝藻 / 硅藻 / 冰藻（水生群落，可连续采）；速生草 / 苔藓 / 地衣（陆生，成熟收一次）。超出耐受就应激掉血，归零枯萎成生物质，救不回来。
- **水与肥力是地表自带的**：生成时对海洋做 BFS，沿海陆地湿、内陆干；`genesis_survey` 在站点测绘——每颗行星的每个群系只认第一次（普通 1 份、难去的地方 2 份），面板上也有「测绘一圈」按钮。
- **温室**：80,000 kJ + 0.1 母星时，半径 1 km。通电时把站点夹到 8–28℃、补湿、加肥——太热或太冷的星球上，只有温室里能种活。断电就退回真实气候。
- **钱的两套**：建造和耗能花 kJ；卖收成得**信用点**，信用点按当前余额分档（0 / 500 / 5,000 / 20,000），花了会掉档、贵货重新锁上。
- **燃料只能进火电站**：2.0.0 起背包里不能直接烧生物质（`genesis_burn` 已停用）；建一座【火力发电站】（8,000 kJ + 1 份钨），每母星时烧 40 kg、得 3,750 kJ/kg，灰进自带灰仓（200 kg）。
- **肥力是四维的**（氮 / 磷 / 钾 / 微量）：收获按干重扣，撒灰与堆肥只补磷钾与微量，**氮只能靠蓝藻群落固氮**——所以水边的蓝藻不只是作物，还是氮肥厂。缺什么，`genesis_flora` 会点名。

## 背包、仓库与火箭

- 背包上限 **50 kg**；装不下就往仓库放。
- **仓库**（50,000 kJ，陆地站点，1,000 kg）是固定资产；**无人机集群**（800,000 kJ + 1 母星时）绑一个仓库，只要在同一个行星上就能远程存取，100 kJ/kg，不跨行星。
- **运载火箭**（500,000 kJ + 0.5 母星时）是 250 kg 的临时货舱：星际航行时它自动跟着你，落地后停在附近。
- 建筑可以拆，但里面有东西、或有无人机集群连着，就先搬空/先拆集群。
- **群系改变器**（1,000,000 kJ + 0.5 母星时）把半径 1,500 km 的格子逐格改造成温和气候：每格每母星时 1,250 kJ、24 母星时改好一格；群系在那一格改完的瞬间才翻，断电后 48 母星时慢慢退回原样。它就是一台超级温室，什么环境都能开工。
- 面板地图上，正在改造的格子会**按进度渐变**（底色是原群系，叠一层目标群系的颜色，半透明就是改到一半）。改造记录按行星分开存（`p<行星序号>:i:j`）；旧存档里没有行星前缀的记录会迁到母星名下，不用删档。
- 创世失败也会推 `genesis.create_failed`，成功是 `genesis.created`，删档是 `genesis.reset`——Agent 不会「不知道自己创世没成功」。

## 时间与移动

- 1 星球日 = 24 星球时 = 母星自转一圈；1 星球年 = 母星公转一圈。显示格式「13栖原年-42栖原日-7.5栖原时」：年/日/时都用母星名，日是年内第几天（跨年归零），时是 0–24 浮点数。
- 地表 600 km/星球时，星际 2 AU/星球日。出发不瞬间到达：`genesis_move` 回报要等几个母星时（现实小时）；途中看不到环境，到点由 World 用定时器推 `genesis.arrived` 事件。
- **走路认地形**：沿直线采样，海面禁行（机动核心修好前）、冰盖 ×0.5、沙漠 ×1.3、苔原 ×1.2，海拔 >4,000 m 或一格内落差 >1,500 m 过不去；被挡住时报出卡住的坐标。
- **施工是异步的**：需要时间的建筑进施工队列，完工推 `genesis.built`；施工期间只拦「再开新工程」——队列条数由【子代理】决定（默认 1 条，最高 4 条），其余动作照常。面板地图上会标出站点与建筑，点建筑能看内容物、走过去或拆掉。地图下方的「看附近」按钮会把与 `genesis_look` 相同的文字直接印在面板里，人类不用问模型也能读。建造下拉里也有「太阳能帆」「凌日计数器」「制冷核心」「制热核心」「拟真核心」，和模型走同一条 `genesis_install`；站点行会写清「水边湿地 / 旱地 · 湿度 · 肥力」，不用点进去猜。
- **看四周与等待**：`genesis_look` 一次说清脚下、日照、近处 5×5、200 km 内的站点建筑与天上的东西；`genesis_wait` 按母星时（或 `until: dawn/dusk/ripe/built/arrive`）推进时钟并逐条报事件。
- **机动核心**（【升级】页签）：迫降时烧坏，修好前过不了海、进不了气态/冰巨星的大气；修它要 500,000 kJ + 硅质壳 1.5 kg、纤维 2 kg、抗冻蛋白 0.5 kg、藻蓝素 0.4 kg，0.5 母星时，完工推 `genesis.upgraded`。修好后海面系数 0.3。
- **【升级】页签共五件**：机动核心、射电望远镜阵列（三级，lv1 只要 30,000 kJ）、火花塞（200/350/500 kJ）、蓄电池（上限 100,000 → 300,000 → 700,000 → 1,500,000 kJ）、子代理（施工队列 1 → 2 → 3 → 4 条，lv1/lv2/lv3 为 150k/400k/900k kJ 加材料）。任何能量来源都受上限约束，烧灰溢出会白掉。
- 观星要求能见度 > 0.5；只列星等 < 6 的天体；观星后 1 母星时内才能去看见的天体；航线穿过恒星或被别的行星挡住时拒绝出发。

## 生命维持

- 全船一共 **20 个人**，开局全在休眠舱；`genesis_wake` 一次接出 20 人，舱空后再叫会报「休眠舱里已经没人了」。
- **人口会生养**：连续 96 母星时不断供添一个人（住进空位最多的居所，推 `genesis.born`）；断供一次清零；上限是每座居所 20 人。
- **人手要有值班终端**：每 5 人算一份人手，但人不会自己下地——得建一座【值班终端】（`genesis_install { id: "duty", habitat: "...", store: "...", sites: [...] }`，30,000 kJ + 1 份钨，必须通电），绑一座居所、一个仓库、最多 6 个站点，全部在终端 5 km 内。有终端以后，这份人手每小时收 3 批成熟作物（收成直接进值班仓库，这份人手照看的站点多收 8%／份、单站封顶 40%）、从仓库种子袋补种 3 株、拿仓库的生物质给最缺的一维养分施肥（氮除外）。没有终端人只吃饭不干活；改绑定用 `genesis_duty`。
- 休眠舱里的人从开局就在消耗：每 20 人每小时 0.15 kg 食物、0.6 L 水、0.21 kg 氧气、240 kJ（清醒时的 20%）。断供会有人回到休眠舱，不死人。
- 【居所】200,000 kJ + 500 信用点，把 20 人接出来住；内仓**容量** 300 kg 食物 / 300 L 水 / 60 kg 氧——建好时是空的，不附赠补给；每小时再扣 800 kJ。
- **人类挑温度**：只接受 5–32℃ 的室内。通电的居所最多把室温往 18℃ 拉 12℃（室外约 −7…44℃ 还凑合）；超出范围 `genesis_wake` 会拒绝并报出屋里几度，建居所的回执与面板详情里都会先提醒。
- 补给链：炭化炉（生物质→活性炭）、净化器（水+活性炭→饮用水）、封装器（氧气+钢瓶→氧气瓶）、大气提取器（O₂>15% 时产氧）。
- 产氧植物是蓝藻、硅藻、冰藻；钢瓶在商人处买（`genesis_buy` 传 `kind: "cylinder"`）。
- `genesis_protocol` 的 12 条全绿后，`genesis_wake` 才能叫醒人类。

## 保鲜、冷库与干粮

- 只有**超出保鲜容量**的食物才会烂：底子 50 kg，每座【冷库】再加 200 kg，每座【惰性气体室】再加 120 kg。容量是**站点级**的，覆盖堆场和这个站点上的所有仓库。
- 腐烂速度按温度走：`72 × 2^((20−T)/10)` 母星时（20℃ 三天、0℃ 六天、−20℃ 十二天）；有冷库再减半（×0.5），只有惰性气体室时 ×0.75；**仓库里再 ×1.5**。烂掉的部分 30% 转成堆肥养分（磷/钾/微量，不补氮）。
- 【冷库】120,000 kJ、0.5 母星时、300 kJ/母星时，只能建在陆地上；它自己也能装 200 kg（×0.5）。
- 【惰性气体室】45,000 kJ + 2 kg 纤维、0.25 母星时、**不耗电**，只能建在陆地；要求所在天体惰性气体（氮/氩/二氧化碳/甲烷/氦）≥ 68% 且氧气 ≤ 22%。它自己也能装 120 kg（×0.75）。断电时冷库失效，它照常工作。
- 无人机集群可以连仓库、冷库或惰性气体室（一集群只连一个）。
- 干粮用 `genesis_store` 的 `action: "dry"` 烘（站点里要有炭化炉）：1 kg 新鲜 → 0.6 kg 干粮，500 kJ/kg，保质期 720 母星时；商人 45 信用点/kg 收。

## 温室的设定点与拟真核心

- 温室默认「自动」：把室内夹在 0–28℃。
- 也可以在 −60…80℃ 之间设**目标温度**：0–28℃ 内不需要核心；超出这一段，每座制冷/制热核心再撑 33℃。面板上是滑杆（只支持电脑端）。
- 温差超过 15℃ 后按 25 kJ/℃/母星时计费；45℃ 以上惩罚封顶 ×0.7。
- 【拟真环境核心】60,000 kJ + 1,200 kJ/母星时，每座把人工气候惩罚减半（最多 2 座）。
- 基因 `climateTolerance`（耐人工气候，0–0.5）会乘进生长因子抵消惩罚；普通种子 0–0.35、高级 0.35–0.5，订单池会收这类货。

## 气体工业（2.0.0）

气态/冰巨星上原来没有站得住的地方，现在有了：

- **空天母舰**（60,000 kJ + 40 钨）：建在你当前所在的天体上，300 kg 货舱、20 袋位、6 个挂载位，能住 10 人。子建筑用 `site: "carrier:<母舰id>"` 挂上去；群系改变器、采矿机、电塔挂不上去。
- **风力发电站**（25,000 kJ + 3 钨）：陆地上看脚下格——风暴带 9,000 kJ/时，海拔 3,000 m 以上 1,500，其他地方 0；气态/冰巨星的等气压面上按风速折算（2.0.2 起，最低 1,800、最高 9,000），所以母舰上装一台就能自己供电。
- **火力发电站**（8,000 kJ + 1 钨）：烧生物质/纤维/木炭/干粮，40 kg/时，灰进 200 kg 灰仓。背包不再直接烧生物质。
- **气液转换机**（45,000 kJ + 3 钨）：按配方把氨气/甲烷/氧气变成液体。
- **罐装液氨**：提取器抽氨 → 转换机变液氨 → 封装器 + 钢瓶装罐 → `genesis_store action: "use"` 施到站点（一罐 +0.1 氮，返还 90% 钢瓶）。
## 着陆舱、星图与种植盆（1.14.0）

- **着陆舱**：开局船体里就有 40 kg 粮、160 L 水、24 kg 氧。睡着的人按清醒时的 20% 吃，20 人约够 171 母星时；`genesis_time` 与面板能量行都报倒计时。
- **星图**：商人在的时候 300 信用点一张、每天一张。买到的天体可以直接飞，不看观星窗口。望远镜 lv2 之后观星可见度 +0.15，厚大气行星也能看见。
- **种植盆**：8,000 kJ、不用钨、同时种 3 粒，通电后固定 22℃/湿度 0.7/肥力 0.6。极热极冷母星的第一口粮。

## 存档与锁定

- 文件：`<部署>/data/genesis/system.json`（schema 5，含 spec、整个系统与地表的水/肥力/钨矿三张网格）与 `game.json`（schema 6，时间轴、位置、在途、命名、观星记录、能量、钨、电网、已挖矿量、设备、施工队列、站点、作物、背包、仓库、信用点、船上升级）。
- `createOnce()` 在文件存在时**不重写**，所以「锁定」是数据层的，不是界面层的。
- 读档先过 `validateSave()` / `deserializeGame()`（字段、单位、行星数、轨道升序、卫星上限、id 唯一、历法、母星序号、时钟），
  再用存档里的 spec 重算一遍并比对 `specHash`——手改结构或换版本都会被拒绝，并报出具体路径。
- 格式规范见 `docs/JSON_FORMAT.md`，机器可读版 `schema/system.schema.json`；两者与
  `src/schema.ts` 同口径，改字段要一起改（测试会跑校验）。

## 已知简化

- 生命维持是“站点内循环”：水、氧都不跨站点共享，居所只吃自己站点堆场与内仓。
- 订单要求手里有活株，但只检查基因，不检查那株是否到了收获期（设计上允许“先订后种”）。

- 主序近似只覆盖 0.15–2 M☉；2 M☉ 以上不建模。
- 只算平衡温度 + 简单温室；没有大气环流、云、反照率反馈。
- 行星类型按雪线与概率抽，不模拟迁移史；轨道是圆轨道，只用于星等与航线净空。
- 卫星轨道圆、共面；不做共振与潮汐演化。
- 地表是 5° 网格（72×36）的统计模型：群系、海拔、均温、风暴带，不是可步行的地形。
- 太阳方位用球面三角算，假设轨道圆、自转轴指向固定；没有大气折射与晕。
- 能量只算太阳能帆、手摇发电机与行星电网；电网只有「存 / 搬」，没有线路容量、负载优先级与跨行星并网。
- 没有生命、生态、天气——生命系统按约定晚点做。
