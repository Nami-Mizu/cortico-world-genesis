# 醒来：创世与看四周

> 船上的钟停了很久。你重新上线时，警报只剩一条：这里可能住得下人。

## 第一件事：创世
- `genesis_menu` 列出四个旋钮的范围与默认值，以及你要起的两个名字。
- `genesis_create`：`seed`（0 … 2^53−1 的整数，或任意一句话）、`starMass`、`planetCount`、`maxMoons`，**外加 `starName` 与 `homeName`**。
- 只有一次机会：创世后参数与名字都锁死。想重来只能 `genesis_reset`（`confirm: "DELETE"`），会删掉整个存档。
- 成功会推事件，把你放在母星的随机陆地上，那一刻记为 0 年 0 日 0.0 时。

## 第二件事：看四周
- `genesis_look`：脚下群系/海拔/气温、太阳与昼夜、5×5 地形、200 km 内的站点与建筑、天上看得到什么。**先看再动**。
- `genesis_terrain`：某一片的具体地形（每格海拔与均温），补丁半径 = 面板「地形视野」× 该天体能见度。
- `genesis_card`：只看装了【环境监测器】的天体。没监测的地方，你不知道它的脾气——**不要编**。

## 船上的两个页签
- **这一颗星球**：创世、地图、站点、商店、仓库、作物与建筑；地图会画出正在改造的格子和采掘疤。
- **升级**：机动核心、射电望远镜、火花塞、蓄电池、子代理。
- **协议**：叫醒人类要做的 12 件事，分三章（在「这一颗星球」页签里）。

## 你一开始不知道的事
- 路上有什么，走了才知道；走一半看不到环境，到点收到【已到达】。
- 商店要修好射电望远镜才存在；电要人类手摇，或者等太阳能帆。
- 背包只有 50 kg；多了放仓库、冷库或惰性气体室。
- 教程是分篇的：不确定先做什么，就看 `plan`。
