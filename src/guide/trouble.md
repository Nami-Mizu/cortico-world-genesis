# 卡住了怎么办

> 别硬撑。船上的东西坏了不是你的错，但你得先知道哪坏了。

## 「我没有能量」
- 请人类按动能发电机（一次 50 kJ），或建太阳能帆等白天，或建【火力发电站】烧存下的燃料。
- `genesis_time` 看能量与上限；上限满了再多也存不下。

## 「能量掉得很快」
- 多半是维护费：`genesis_recipes` 看单价，机械臂/终端/无人机是耗电大户。
- 偏远星球的电塔不够就断电——先减设备，别硬撑殖民地。

## 「商店不存在 / 商人不在」
- 商店要望远镜 lv1；营业时间按等级（lv1 只有 12:00–14:00）。
- 用 `genesis_wait until: dawn` 或等到 12 点，别一直问。

## 「走不过去」
- 海面要机动核心；高山/大落差本来就过不去。换个坐标绕开，报错里给了挡路的点。
- 移动途中看不到环境是设计：等到【已到达】再看。

## 「作物枯了」
- 看 `genesis_flora` 的「应激」与温度/湿度：多半太冷/太热/太干，或缺四维中的一项。
- 温室能救一部分；超出能力就换站址——比硬种划算。
- 温室也救不了，就是「太热/太冷，温室无能为力」：要加制冷/制热核心，或者换行星。

## 「食物烂了」
- 只烂超出保鲜容量的部分：加冷库/惰性气体室、或把仓库里的挪进冷库。
- 仓库比地窖烂得快（×1.5），别把一季收成全塞仓库。

## 「机械臂不搬」
- 看四件事：臂展（5 km）、目标袋位/容量是否满、有没有电（维护费扣到 0 就停）、`items` 白名单是不是把它要搬的东西筛掉了。
- 成环不报错，只会每天提醒一次——想停就把其中一段的输入改掉（`genesis_link`）。

## 「交易终端不卖 / 不收」
- 需要：终端通电、商人开张（12:00 后）、无人机连到它（或者你在同站点）、当天额度没用完。
- 缓冲满（200 kg / 20 袋）就拒收：让无人机或机械臂清掉。

## 「我看不到那颗行星」
- 没装环境监测器。先到那儿，再 `genesis_install { id: "monitor" }`（150,000 kJ）。
- 星际航行还要观星窗口：先 `genesis_stargaze`。

## 「队列满了 / 建不了」
- 同时只能开 N 个工程（默认 1，子代理三级到 4）。先等一条空出来，或升【子代理】。

## 「存档读不了」
- 存档 schema 升级过，旧档会提示需要 `genesis_reset`。名字与参数都锁在存档里，重开就是重开。
