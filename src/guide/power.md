# 能量、设备与飞船

> 你醒来时电池里还剩一点迫降前攒下的电（2,000–5,000 kJ，看种子）。船上唯一还听话的东西，是那把要人摇的手柄。

开局 2,000–5,000 kJ，上限 100,000 kJ（【蓄电池】三级 → 1,500,000 kJ）。

## 电从哪来
- **动能发电机**（面板上，人类专用）：每按一次 **50 kJ**，0.5 秒冷却。**你不能按**——需要电就明确请人类动手。
- **火花塞**（升级）：每次 200 → 350 → 500 kJ。
- **太阳能帆**：**6,000 kJ** 一座，建在脚下这块**陆地**上，白天每母星时 **7,000 kJ**、夜里 0；每颗行星最多 10 座，气态/冰巨星不能建。它按**自己的经纬度**照太阳：赤道常年一半一半，高纬冬天短、夏天长，极地有极昼极夜——选址是有意义的。白天略强于烧生物质。
- **风力发电站**：25,000 kJ + 3 份钨。建在陆地上时看脚下这一格——风暴带（群系 12–16）每母星时 9,000 kJ，海拔 3,000 m 以上 1,500，其他地方 0。
  建在**气态/冰巨星的等气压面**上（挂在空天母舰的挂载位、`site` 写 `carrier:<母舰 id>`）则按风速折算：风暴越猛给得越多，最低 1,800、最高 9,000——所以母舰上装一台风机，就等于有了自己的电。
- **火力发电站**：8,000 kJ + 1 份钨，哪里都能建。每母星时烧 40 kg 燃料（生物质 3,750 kJ/kg），灰进自带灰仓（200 kg，就是草木灰）。背包里不能直接烧了——燃料必须先放进它的燃料仓。
- 电到上限后再充，多出来的白掉（火力发电站会提示）。
- 开局电池里还有迫降前的残电（2,000–5,000 kJ，看种子）。

## 维护费
- 建筑与设备按母星时扣维护费（帆、温室、冷库、臂、终端、无人机…各有单价，见 `genesis_recipes`）。
- 先扣**本地电网**（有整流电塔的行星），不够再扣电池。见 `mine`。
- 电扣到 0，该建筑当天停摆（温室退回真实气候、臂不搬、终端不结算），但不会坏。

## 设备
- **环境监测器**（**150,000 kJ** + 0.1 母星时）：一个天体一台；母星那台还会解锁恒星全貌。
- **凌日计数器**（150,000 kJ + 0.1 母星时）：装了 `genesis_transit` 才告诉你在第几行星/卫星。
- **水泵**（20,000 kJ）：半径 3 km 的旱站点 +0.2 湿度；温室锁水也弱。
- 设备只能装在**你所在的那个天体**上。
- 装与建统一用 `genesis_install`，`id` 写清楚；忘了 id 就翻 `genesis_recipes`。
