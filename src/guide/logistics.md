# 容器与自动化：无人机、终端、机械臂

> 一开始你什么都得自己搬。后来船学会了自己搬，你就只剩「决定往哪搬」。

## 容器
- 背包 50 kg；【仓库】【冷库】【惰性气体室】各按容量装散货；【交易终端】是收货口（干散 200 kg）。
- 散货重量计入容量；种子袋按**袋位**算：仓库/冷库/惰性气体室/交易终端各 **20 袋**，一袋草籽才 20 克。
- 仓库里的东西烂得更快（×1.5），能进冷库就进冷库。

## 无人机（行星尺度）
- 【无人机集群】（800,000 kJ + 3 份钨）的 `serves` 指向一个容器（仓库/冷库/惰性气体室/交易终端），2,000 km 内把同行星的容器连成一张网。
- 它不搬货，只提供「通路」：有了它，交易终端才能取到远处的容器。
- 无人机不能跨行星连线。

## 交易终端（自动卖出 / 自动买入）
- 【交易终端】（60,000 kJ + 2 份钨）在每天商人开张后自动卖一次 `target` 指定的资源（默认尾矿，净价 0）。
- 它默认吃**同一颗行星上的每一个容器**——包括你想留着的缓冲。
- 传 `buySpecies` 让它每天自动买 **1 袋**随机种子（按阶梯价付 kJ），货落在终端缓冲里。

## 仓储终端（编排表）
- 【仓储终端】（20,000 kJ + 1 份钨 + 0.3 母星时）不是仓库，是一张**货源编排表**。
- 链路：无人机 `serves` 指向仓储终端 → 仓储终端 `feeds` 指向交易终端 → 终端只取表里放行的容器。
- 每个容器在这颗行星上有个固定槽位（0、1、2…），`genesis_route { container, priority }` 写「槽位 → 优先级」：数字越大越先取、0 最低、-1 或不写就完全不动。
- 没连仓储终端时行为不变（还是吃全部容器）。

## 机械臂（站点内部）
- 【机械臂】（15,000 kJ + 1 份钨 + 0.2 母星时）：`inputs` 几个容器 → `output` 一个容器，臂展 **5 km**、**40 kg/母星时**、每 kg 0.05 kJ、每颗行星最多 **20 座**。
- 先整袋搬种子、再搬散货；设了 `items` 白名单时只管散货、不碰袋子。
- 改线用 `genesis_link`（不传的字段保持原样，`items: []` 恢复全搬）。
- 允许接成环，但每天 12:00 前会推一次 `genesis.arm_cycle` 提醒——环不烧你的信用点，只烧电。

## 两条典型产线
- **尾矿**：采矿机 → 站点堆场（500 kg 满则停）→ 机械臂 → 交易终端 → 商人每天收 50 kg。
- **粮食**：站点收割 → 机械臂 → 冷库（×0.5）→ 需要时再搬回温室旁的仓库。

## 谁先谁后
- 先电、再通路（无人机）、再编排（仓储终端）、最后才是臂。
- 臂和终端都在扣维护费：没有稳定发电时，自动化会先把电池吃空。
