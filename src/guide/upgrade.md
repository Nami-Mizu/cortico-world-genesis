# 升级：修船坞

> 船坞里的灯一盏一盏亮起来。像有人在黑暗里应了你一声。

【升级】是单独的页签，也是这艘船的故事线。

## 机动核心（初始是坏的）
- 修复：500,000 kJ + 硅质壳 1.5 kg + 纤维 2 kg + 抗冻蛋白 0.5 kg + 藻蓝素 0.4 kg，0.5 母星时。
- 修好前：**过不了海**、**进不了气态/冰巨星的大气**（星际航行会被拒）。
- 修好后：海面移动系数 0.3（慢，但能过）。

## 射电望远镜（lv0 没有商店）
- lv1：**30,000 kJ，只要能量**，0.5 母星时 → 解锁商店（12:00–14:00）。
- lv2：800,000 kJ + 硅质壳 5 kg + 纤维 4 kg + 地衣酸 0.4 kg，1 母星时 → 窗口到 17:00、限额 ×1.3。
- lv3：1,800,000 kJ + 硅质壳 12 kg + 纤维 10 kg + 藻蓝素 0.6 kg + 抗冻蛋白 0.3 kg，1.5 母星时 → 窗口到 23:00、限额 ×1.7。

## 火花塞与蓄电池
- 火花塞：200 / 350 / 500 kJ（手摇一次），三级。
- 蓄电池：100,000 → 300,000 → 700,000 → 1,500,000 kJ，三级。

## 质谱仪与蓝图
- 质谱仪：25,000 kJ + 1 份钨 + 0.5 母星时，装好后 `genesis_veins` 能扫附近 2,000 km 的矿（每 6 母星时一次）。
- 蓝图结构优化：200,000 kJ + 3 份钨 + 2 kg 纤维，之后建筑省 25% 的钨。

## 子代理（施工队列）
- 默认只有 1 条队列；lv1 150,000 kJ + 纤维 2 kg → 2 条；lv2 400,000 + 硅质壳 4/纤维 3 → 3 条；lv3 900,000 + 硅质壳 8/纤维 6/藻蓝素 0.4 → 4 条。
- 队列满时新工程会被拒；已开工的工程不影响你走动/观星/存取。

## 怎么升
用 `genesis_upgrade`，`id` 传 `mobility_core` / `telescope` / `spark_plug` / `battery` / `subagent` / `spectrometer` / `blueprints`；不带 id 列清单。
